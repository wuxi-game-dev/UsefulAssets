# UsefulAssets

这里是**无锡学院游戏开发部**用于存放、整理和共享游戏开发素材的仓库。

你可以在这里分享自己收集、制作或整理的各种游戏素材，包括但不限于：角色、场景、UI、音效、音乐、特效、字体等。

希望大家能够遵循以下规范，让素材更容易被其他成员找到和使用。

## 📁 文件结构

根目录下请先创建一个**属于自己的文件夹**，文件夹名称建议使用自己的 GitHub 用户名。

例如：

```text
-Ouse
 └─ 2D横板游戏素材基础包
     ├─ 2D横板游戏素材基础包.zip
     └─ README.md
```

其中：

* `Ouse`：素材上传者的文件夹。
* `2D横板游戏素材基础包`：素材包文件夹，可以根据素材内容自行命名。
* `.zip`：实际的素材文件，可以是一个或多个文件。
* `README.md`：素材说明文件，**每个素材包都需要包含一个 README.md**。

一个上传者可以创建多个素材包，一个素材包也可以包含多个素材。

## 📝 README.md 规范

每个素材包中的 `README.md` 建议按照以下格式编写：

```markdown
# 素材名称

来源：https://zerie.itch.io/tiny-rpg-character-asset-pack

内容：人物角色

风格：2D像素、中世纪

介绍：西欧风格的人物角色素材，非常适合用于 2D 横版或 2.5D 游戏。
```

### 示例

# Tiny RPG Character Asset Pack

**来源：** https://zerie.itch.io/tiny-rpg-character-asset-pack

**内容：** 人物角色

**风格：** 2D 像素、中世纪

**介绍：** 西欧风格的人物角色素材，非常适合用于 2D 横版或 2.5D 游戏。

## ⚠️ 注意事项

1. **请注明素材来源**，方便其他成员了解素材出处及授权协议。
2. 上传前请确认素材的**许可证（License）是否允许使用、修改和再分发**。
3. 不要上传来源不明、无法确认版权的素材。
4. 素材文件较大时，建议使用压缩包进行整理。
5. 尽量保持文件夹和文件名称清晰、易于理解。
6. 如果素材包含特殊的使用要求，请在 `README.md` 中注明。
